# Política de segurança

**Não divulgue vulnerabilidades em issues, discussões ou pull requests públicos.**

Se o repositório tiver a opção GitHub **Security → Advisories → Report a vulnerability**, use-a para abrir um relato privado aos mantenedores. Caso essa opção não esteja ativa, solicite ao proprietário do repositório um canal privado antes de enviar detalhes técnicos, segredos ou provas de conceito.

Não inclua chaves, tokens, dados pessoais nem reproduções de abuso em logs ou screenshots públicos. A equipe fará triagem e definirá a correção antes de qualquer divulgação.

O GitHub Pages publica recursos estáticos e, por isso, seus arquivos JS, HTML e JSON de configuração pública são legíveis por qualquer visitante. Proteções de dados devem estar no backend; ofuscação de JS ou bloqueio de F12 não representam controle de acesso.
